## 🔥 মূল সুবিধাসমূহ (Key Features)

- **🍱 মেস মিল এন্ট্রি (Daily Meal Entry)**:
  - ৪ জন মেম্বার (**Rejaul, Tafiqul, Rafiul, Samiul**) এর দৈনিক মিলের হিসাব রাখার সুবিধা।
  - স্ট্যান্ডার্ড 0-3 মিল নির্বাচন অথবা কাস্টম মিল সংখ্যা ইনপুট দেয়ার অপশন।
  - অটোমেটিক আজকের তারিখ সেভ থাকা, সাথে পছন্দমতো তারিখ নির্বাচনের সুবিধা।

- **💰 মেস জমা এন্ট্রি (Member Deposit Entry)**:
  - যেকোনো সদস্যের মেস জমা সরাসরি Google Sheet এর কলামে অটোমেটিক যোগ হওয়ার ব্যাকএন্ড সুবিধা।

- **💵 খাবার ওয়ালা (ক্যাটারিং) পরিশোধ এন্ট্রি (Catering Payment)**:
  - ক্যাটারিং সার্ভিস পাওনা টাকা পরিশোধ করলে তা অটোমেটিক প্রথম খালি ঘরে যুক্ত করা।

- **📊 লাইভ সদস্যভিত্তিক সামারি টেবিল**:
  - মোট মিল সংখ্যা, মোট খরচ, মোট জমা টাকা এবং বর্তমান স্টক ব্যালেন্স রিয়েলটাইমে গুগল শিট থেকে লাইভ প্রদর্শন।

- **🍛 নাবিলা ক্যাটারিং বিল বিবরণী (`catering-view.html`)**:
  - OLED ডার্ক মোড গোল্ড/এমারেল্ড লুক।
  - মোট মিলের বিল, পরিশোধের পরিমাণ এবং বকেয়া টাকা পাওয়ার হিসাব স্পষ্ট বড় ফন্টে প্রদর্শন।
  - ৩০ দিনের দৈনিক মিল বিবরণী পপ-আপ দেখার সুবিধা এবং আজকের তারিখের লাইভ স্ট্যাটাস।

## 📌 ধাপ ১: Google Sheet-এ Apps Script যুক্ত করা

১. আপনার গুগল শিটটি (Google Sheet) ব্রাউজারে অপেন করুন।
২. উপরের মেনু থেকে **Extensions** > **Apps Script**-এ ক্লিক করুন।
৩. এডিটরের সব কোড মুছে ফেলে `Code.gs` ফাইলের কোডটি হুবহু পেস্ট করুন এবং সেভ করুন।

---

## 📌 ধাপ ২: Apps Script ডেপ্লয় (Web App Deployment) করা

১. উপরে ডান কোণায় **Deploy** > **New deployment**-এ চাপ দিন।
২. গিয়ার (⚙️) আইকন থেকে **Web app** সিলেক্ট করুন।
৩. নিচের অপশনগুলো নির্বাচন করুন:
   - **Description:** Catering Meal Web App
   - **Execute as:** Me (`your-email@gmail.com`)
   - **Who has access:** Anyone
৪. **Deploy** বাটনে চাপ দিয়ে প্রয়োজনীয় অনুমতি (Authorization) দিন।
৫. জেনারেট হওয়া **Web App URL**-টি কপি করে নিন।

---

## 📌 ধাপ ৩: HTML ফাইলে Web App URL বসানো

`index.html` এবং `catering-view.html` ফাইলের এই অংশটিতে আপনার কপি করা URL বসান:

```javascript
const GOOGLE_SCRIPT_URL = "YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
```
